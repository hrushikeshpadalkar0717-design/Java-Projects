This repository contains a collection of basic to intermediate Java projects developed to strengthen core Java concepts, Object-Oriented Programming (OOP) principles, 
and Data Structures & Algorithms (DSA) fundamentals.Each project is written in a simple and understandable manner, making it suitable for students, beginners, and 
intermediate learners.

📌 Projects Included:
Some of the projects available in this repository are:
   1.CDM_Machine.java – Simulates a Cash Deposit Machine with basic banking operations.
   2.EventManagement.java – Manages event details using OOP concepts.
   3.FlightReservationSystem.java – A console-based flight booking and reservation system.
   4.Hospital.java – Hospital management system handling patients and records.
   5.Student Management System – Uses linked lists for student record management.
More Java programs covering different problem statements and concepts
